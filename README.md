# Тестирование портала «Конференции.РФ»

МДК.05.03 «Тестирование информационных систем». Терзи Эллия.

Объект тестирования: учебный портал из репозитория `conference-django` (Python, Django, SQLite). Все задания выполнены на нём.

## Задания

| Папка | Что внутри |
|---|---|
| `Задание 1. Чек-лист, тест-кейсы, баг-репорт` | чек-лист на 16 пунктов, 5 тест-кейсов, 7 баг-репортов, `check_flows.py` (26 проверок сценариев) |
| `Задание 2. Анализ запросов в DevTools` | GET страницы документации Django и POST входа на портале: метод, код, заголовки, тела |
| `Задание 3. Тестирование форм` | 40 проверок регистрации и входа, `check_forms.py` |
| `Задание 4. Автотест входа на Selenium` | 10 тестов, Page Object, явные ожидания, снимок при падении |
| `Задание 5. Смоук-тесты и CI` | 5 смоук-тестов, запуск в GitHub Actions (.github/workflows/smoke.yml), отчёт pytest-html |

В каждой папке есть `README.md` и снимки в `screens`. Отчёт по МДК.05.03 лежит в корне: `Отчет МДК.05.03.docx`.

## Что нашла

Семь настоящих ошибок портала: логин ADMIN при существующем admin, пароль из пробелов, пароль равен логину, почта длиннее 254 символов, оценка отзыва вне 1-5, нет значка сайта, вошедший открывает регистрацию. Все исправлены в `conference-django`, после этого проверки сценариев 26 из 26, формы 40 из 40, автотесты входа 10 из 10, смоук 5 из 5.

## Запуск

Смоук-тесты запускаются в GitHub Actions на каждый push, последний прогон: вкладка Actions репозитория (первый успешный: https://github.com/elulunna2007-beep/conference-qa/actions/runs/42128585948).

Нужны Python 3.12 и Chrome. Репозиторий портала должен лежать рядом с этим:

```
git clone https://github.com/elulunna2007-beep/conference-django
git clone https://github.com/elulunna2007-beep/conference-qa
cd conference-qa
pip install -r requirements.txt
python -m pytest
python -m pytest -m smoke
```
Портал тесты запускают сами (временная база, порт 8101). Другую папку с порталом можно указать переменной `PORTAL_DIR`.

Структура: `portal_server.py` запуск портала, `conftest.py` драйвер и снимок при падении, `pages` Page Object.
